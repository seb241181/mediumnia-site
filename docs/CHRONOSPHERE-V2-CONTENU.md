# CHRONOSPHÈRE — V2 DU CONTENU DES TIRAGES

Document de travail validé avec Sébastien.

## Principe produit

Le but n’est pas de rendre les tirages simplement plus longs, mais plus riches, plus structurés, plus personnels et plus utiles.

Les deux offres doivent délivrer exactement la même qualité de contenu :
- 5,00 € TTC = 1 tirage complet ;
- 9,90 € TTC = pack de 3 tirages complets.

Le pack est une remise sur le volume, pas une version premium du contenu.

## Structure cible d’un tirage

1. **Votre tirage en une phrase**
   - résumé immédiat ;
   - tendance générale : favorable / favorable mais en construction / mitigée / peu porteuse actuellement.

2. **La photographie de l’instant**
   - position actuelle ;
   - dynamique dominante ;
   - tension ou enjeu principal.

3. **La fréquence principale**
   - lecture approfondie de la carte centrale ;
   - ce qu’elle ouvre ;
   - ce qu’elle demande ;
   - lumière ;
   - vigilance.

4. **Les deux résonances**
   - lecture des cartes secondaires ;
   - surtout leur effet sur la fréquence principale.

5. **Ce que racontent vos trois fréquences ensemble**
   - lecture synthétique du triangle complet ;
   - éviter trois mini-fiches indépendantes.

6. **Le ciel de naissance et le contexte astrologique**
   - utiliser uniquement les éléments réellement utiles au tirage ;
   - expliquer Ascendant, MC, maisons, transits ou autres facteurs en langage clair ;
   - éviter la surcharge technique.

7. **La ligne de temps**
   - maintenant ;
   - phase de préparation ;
   - fenêtre secondaire ;
   - fenêtre prioritaire ;
   - point de vigilance ;
   - pour chaque période : ce qui est favorisé / ce qu’il vaut mieux éviter / ce qu’on peut faire.

8. **Les deux chemins possibles**
   - « Si vous maintenez la dynamique actuelle… » ;
   - « Si vous modifiez cet élément… » ;
   - présenter des trajectoires possibles, jamais un futur figé.

9. **Vos leviers concrets**
   - à faire maintenant ;
   - à préparer ;
   - à ne pas forcer.

10. **La question que Chronosphère vous renvoie**
    - une vraie question d’introspection liée au tirage ;
    - éviter les formulations génériques.

11. **Acte de réalignement**
    - geste ;
    - phrase / décret d’ancrage.

## Pack de 3 — évolution entre les tirages

À étudier pour une V2 ultérieure :

**Évolution depuis votre précédent tirage**
- énergie qui revient ;
- tendance qui se renforce ou s’inverse ;
- fenêtre temporelle qui se rapproche ;
- problématique qui persiste ;
- nouvel élément apparu.

L’objectif est de transformer le pack de 3 en suivi d’une ligne de temps, et pas seulement en trois lectures indépendantes.

## Règle éditoriale centrale

Chronosphère parle de dynamiques, possibilités, tendances et fenêtres temporelles. Il ne présente jamais un événement futur comme une certitude ni comme une date garantie.

## Idée de positionnement

Le résultat doit donner une lecture rapide en 30 secondes pour les personnes pressées, puis une lecture complète et approfondie pour celles qui veulent aller plus loin.

# ROADMAP PRODUIT — IDÉES À REPRENDRE APRÈS LES CHANTIERS EN COURS

Ces idées sont volontairement consignées maintenant afin de ne pas les perdre. Elles ne doivent pas détourner le travail en cours : d’abord stabiliser Chronosphère (paiement, reprise par e-mail, tests finaux) et le retour depuis l’Espace Élèves, puis revenir à cette roadmap.

## 1. Relier les produits en un vrai parcours MediumIA

Objectif : éviter un site composé de pages indépendantes et créer un écosystème cohérent.

Exemple de parcours :
- Oracle gratuit ;
- proposition naturelle d’approfondissement avec Chronosphère ;
- après Chronosphère :
  - approfondir avec un praticien ;
  - ou apprendre à développer ses perceptions via la Formation ;
- après une conférence ou un rendez-vous : proposer les ressources MediumIA pertinentes.

Principe : chaque produit doit pouvoir conduire vers une prochaine étape logique, sans pression commerciale inutile.

## 2. Créer « Mon MediumIA » — espace utilisateur facultatif

L’achat de Chronosphère doit rester possible sans compte.

Après un achat, proposer facultativement :
**« Créer gratuitement mon espace pour conserver mes tirages. »**

Contenu potentiel :
- historique Chronosphère ;
- crédits de pack restants ;
- rendez-vous réservés ;
- conférences achetées ;
- accès Formation si acheté ;
- replays éventuels ;
- préférences utilisateur.

Le parcours sans compte continue de fonctionner avec les liens sécurisés envoyés par e-mail.

## 3. Faire de Chronosphère un produit vivant dans le temps

Le pack de 3 ne doit pas seulement être une remise tarifaire.

À terme, les tirages 2 et 3 peuvent inclure une section :
**« Évolution depuis votre précédent tirage »**

Comparer notamment :
- fréquence dominante ;
- tendance générale ;
- fenêtre temporelle ;
- point de vigilance ;
- problématique persistante ;
- nouvel élément apparu.

Positionnement cible : suivre une trajectoire dans le temps plutôt que vendre trois réponses indépendantes.

## 4. Ajouter de la preuve avant l’achat

Créer un vrai exemple public complet de tirage Chronosphère avec un profil fictif clairement indiqué comme démonstration.

But : permettre à l’utilisateur de voir exactement la qualité du résultat avant de payer.

Même logique pour la Formation :
- extrait réel d’un module ;
- exemple d’exercice ;
- aperçu de l’assistant MediumIA ;
- aperçu de l’expérience élève.

## 5. Développer le Réseau MediumIA comme une place de marché humaine

Chaque fiche praticien pourrait contenir :
- spécialités ;
- présentation ;
- consultation en présentiel / visio ;
- zone géographique ;
- disponibilités ;
- tarifs ;
- bouton de prise de rendez-vous.

À terme :
- avis uniquement après un rendez-vous réellement réalisé ;
- événements / ateliers / conférences du praticien ;
- outils professionnels MediumIA reliés à sa fiche.

Positionnement différenciant : **IA + apprentissage + outils spirituels + vrais praticiens sur une même plateforme.**

## 6. Développer la rubrique Conférences

Vision cible :
- page « Prochaines conférences » ;
- réservation et paiement sur MediumIA ;
- génération automatique du lien visio ;
- e-mail de confirmation ;
- présence / accès sécurisé ;
- questions des participants récupérées et triées par IA ;
- résumé des questions les plus pertinentes ;
- replay disponible pendant une durée définie.

À terme, ouvrir la possibilité aux praticiens du Réseau de proposer leurs propres conférences avec modèle de commission MediumIA.

## 7. Créer du contenu gratuit réellement utile

Ne pas produire un blog générique uniquement pour le référencement.

Créer des contenus qui démontrent la qualité de MediumIA :
- comment reconnaître une intuition ;
- médiumnité ou imagination ;
- comment préparer une séance ;
- exercices gratuits ;
- mini-tests ;
- extraits de Formation ;
- explications simples de notions spirituelles.

Chaque contenu peut orienter naturellement vers :
- Oracle ;
- Chronosphère ;
- Formation ;
- Réseau / praticien.

## 8. Créer un Journal MediumIA

Idée à fort potentiel de fidélisation.

L’utilisateur pourrait enregistrer :
- intuition ;
- rêve ;
- synchronicité ;
- ressenti ;
- tirage ;
- événement observé ensuite.

Quelques semaines plus tard, il peut noter ce qui s’est réellement passé.

À terme, MediumIA peut l’aider à observer ses propres tendances :
- types de ressentis les plus récurrents ;
- thèmes les plus présents ;
- intuitions confirmées / non confirmées selon ses propres notes ;
- évolution de ses perceptions dans le temps.

Principe : outil d’observation personnelle, pas prétention à prouver objectivement le paranormal.

## 9. Priorité recommandée

Ordre cible après les chantiers déjà commencés :

1. Chronosphère impeccable : paiement, crédits, reprise par e-mail, tests finaux ;
2. retour vers MediumIA.fr depuis l’Espace Élèves ;
3. enrichissement V2 du contenu Chronosphère ;
4. parcours commercial et navigation entre les produits ;
5. exemple public complet de Chronosphère ;
6. « Mon MediumIA » facultatif ;
7. rubrique Conférences ;
8. enrichissement du Réseau ;
9. Journal MediumIA ;
10. contenus gratuits structurés autour de l’écosystème.

## Principe directeur de la plateforme

MediumIA ne doit pas devenir une accumulation de fonctionnalités. La priorité est de connecter les briques déjà fortes entre elles afin de transformer le site en plateforme cohérente, avec un parcours clair : découvrir, expérimenter, approfondir, apprendre, rencontrer et revenir.
